Анализ A/B-теста: влияние нового формата пуш-уведомлений

Цель
Оценить влияние нового формата пуш-уведомлений на конверсию и средний чек клиентов, выявить сегменты с максимальным эффектом и подготовить калькулятор для прогнозирования финансового результата внедрения.

Вводные
Проводился A/B-тест: тестовой группе отправлялись уведомления в новом формате, контрольной — в старом.

Метрики
Конверсия клиентов (доля совершивших покупку)
Средний чек на одного клиента
Абсолютный и относительный прирост метрик в тестовой группе
Финансовый эффект (руб.) на уровне торговых точек и городов

Этапы анализа
Изучена структура исходных данных (клиенты, заказы, регионы), выполнена их очистка и подготовка
Проведено объединение таблиц и агрегация показателей по каждому клиенту и торговой точке
Выполнен статистический анализ A/B-теста с использованием t-критерия и критерия Манна-Уитни
Проведена сегментация данных по городам и торговым точкам с повторением анализа на каждом сегменте
Разработана итоговая таблица-калькулятор в Excel для оценки финансового эффекта

Инструменты
Python (Jupyter Notebook): pandas, numpy, matplotlib/seaborn, функции для автоматизации анализа
Статистические методы: t-критерий, критерий Манна-Уитни, расчет p-value
Excel: калькулятор с промежуточными и итоговыми расчетами, таблицы для презентации

Выводы
Наблюдается статистически значимый рост среднего чека в тестовой группе. Эффект устойчив при проверке как параметрическим, так и непараметрическим критериями.
Конверсия в тестовой группе выросла, однако различия не являются статистически значимыми на уровне 95% (p-value = [Z]).

Выявлена неоднородность эффекта по сегментам: положительная динамика зафиксирована в городах-миллионниках, нейтральная — в средних городах, отрицательная — в малых населенных пунктах.

Рекомендации
Рекомендуется внедрить новый формат уведомлений в городах-миллионниках и торговых точках категории, где зафиксирован максимальный положительный эффект.
Для средних городов целесообразно провести дополнительный A/B-тест с увеличенной выборкой, чтобы подтвердить или опровергнуть наличие эффекта при большей статистической мощности.
В малых городах, где зафиксирован отрицательный эффект, рекомендуется отказаться от внедрения нового формата и провести качественное исследование (интервью с клиентами) для выявления причин негативной реакции.
Разработанный Excel-калькулятор позволяет оперативно пересчитывать финансовый эффект при изменении входных параметров (охват, частота отправки, сезонность) и может использоваться для ежеквартального планирования маркетинговых активностей.
